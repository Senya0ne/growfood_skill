# Grow Food Skill — Adapters

Каждый AI-агент ищет инструкции в своём формате. Скопируй нужный файл в проект или домашнюю директорию:

| Платформа | Файл адаптера | Куда положить |
|---|---|---|
| **Claude Code** | `claude-code/CLAUDE.md` | `~/.claude/CLAUDE.md` или корень проекта |
| **Cursor** | `cursor/.cursorrules` | корень проекта |
| **OpenAI Codex** | `codex/AGENTS.md` | корень проекта |
| **Gemini CLI** | `gemini-cli/GEMINI.md` | корень проекта |
| **Hermes** | Основной `SKILL.md` в корне репо | `~/.hermes/skills/growfood/SKILL.md` |

Или просто склонируй весь репозиторий в папку навыков — `SKILL.md` в корне подхватится большинством агентов.
