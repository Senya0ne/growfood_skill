# Grow Food — помощник по меню (Gemini CLI / Antigravity)

Этот файл — адаптер SKILL.md для Gemini CLI и Antigravity. Полные инструкции: `SKILL.md` в корне репо.

## Настройка

```bash
GF="python3 $HOME/.gemini/config/skills/growfood-skill/scripts/growfood.py"
$GF --json <команда>
```

## Инструкции

Следуй инструкциям из `SKILL.md` — сценарии, команды и правила.

Ключевое:
- Для разбора всегда `--json`; пользователю — короткий текст по-русски.
- Скрипт НИКОГДА не вызывает оплату, не обходит капчу.
- `--allow-extra` только с явного согласия пользователя в этом диалоге.
- Не трогай 🔒 дни, снеки, напитки, ручные замены (🔁).
